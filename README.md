# 議事録作成

iPhone・iPadのSafari向けの議事録ツール。アプリ内の録音を停止すると、OpenAI APIで日本語文字起こしと議事録作成を行います。既存の無料手動モードも利用できます。

## 自動モード（従量課金）

1. 会議名・開催日・参加者と作成プロンプトを確認します。
2. 「録音を開始」を押し、Safariのマイク利用を許可します。会議の参加者に録音とAI利用を伝えてください。
3. 画面を開いたまま録音します。「停止して議事録を作成」を押すと文字起こし・議事録作成が順番に進みます。
4. 内容・担当者・期限を確認し、保存・LINE共有します。

初期参加者は大月（専務）、和田（部長）、黒崎（課長）、東（担当）。既存のユーザープロンプトと保存済みデータを維持します。期限未指定時は「本日18:00まで」というユーザーのルールを適用します。

### 制限・復旧

- 録音は最長60分、約1分ごとに独立した音声ファイルに分割します。ブラウザの録音再開処理の境界で短い途切れが生じる可能性があります。
- 分割音声1本あたり最大4,000,000バイト。Vercel Functionsのリクエスト上限を考慮した値です。文字起こしは最大10万文字、プロンプトは最大1.5万文字です。
- 音声は録音停止後にOpenAIへ送信し、文字起こし完了後に全文とプロンプトを送って議事録を作ります。
- 自動モードはChatGPTの契約と別にAPI料金が発生します。使用モデルはgpt-4o-mini-transcribeとgpt-4o-mini。アプリに月額課金の強制停止機能はありません。OpenAI側の残高・通知・利用状況も確認してください。
- 「音声処理を再開」で成功済み音声の再送信を省略します。タイムアウト等で応答を取得できなかったリクエストは、OpenAI側で処理済みの場合でも再試行で再課金される可能性があります。
- 途中の文字起こしはブラウザ内に一時保存します。音声はメモリ内のみです。必要なら各「音声を保存」で端末に保存してください。ページを閉じる・再読み込みする・端末のメモリが解放されると音声は失われます。
- 画面ロックやアプリ切り替え時は録音を中断し、取得できた音声を残します。自動のバックグラウンド録音はできません。画面スリープ抑止はブラウザが対応・許可した場合のみ有効です。
- iOS 27.0.1の実機でのマイク録音・LINE共有は未確認です。まず短い音声で確認してください。

## 無料の手動モード

ボイスメモの文字起こしを貼り付け、「依頼文をコピーしてChatGPTへ」を押します。ChatGPTへの貼り付け・送信後、回答をこのアプリへ戻してLINE共有します。ChatGPT無料版の利用制限は適用されます。この操作はAPIを呼び出しません。

ボイスメモを開くには「ショートカット」で「アプリを開く → ボイスメモ」を作り、名前を「会議を録音」にします。アプリ内の無料手動モードに設定案内があります。

## 開発

Node.js 22以上。外部npm依存なし。

```sh
cp .env.example .env
# ローカルでAPIを使うときだけ.envにOPENAI_API_KEYを設定
npm start
npm test
```

ポートは既定3000。APIキーはサーバー側でのみ使用します。ファイルやログ、GitHubに実際のキーを含めないでください。

## Vercel

本番URL：https://my-shop-bay-eta.vercel.app

`public/`は静的ファイル、`api/`はNode.jsのVercel Functionsです。Production環境変数`OPENAI_API_KEY`が必要です。環境変数の変更は再デプロイ後に適用されます。関数の最大実行時間は180秒に設定しています。

このプロジェクトにはVercel Authenticationの`all_except_custom_domains`保護を設定済みです。既存のvercel.app本番URLでも認証が必要です。独自ドメイン追加・アクセス保護解除時は先に別の利用者認証を導入してください。API自体には独立したユーザーログインや永続的なレート制限はないため、保護を解除して一般公開しないでください。

GitHub自動デプロイは未接続。CLIで`vercel --prod`により公開します。API対応版では`public/`だけを静的ホスティングしても自動モードは動きません。

## データと検証

議事録・文字起こし・プロンプトは同じブラウザ内だけに保存されます。他端末と同期しません。ブラウザデータ削除で失われるため重要な議事録は別途保管してください。音声はサーバーのファイルには保存しません。OpenAI側のデータ取扱いはOpenAI APIのポリシーをご確認ください。

自動テストはAPIの入力検証、秘密情報を含めないエラー処理、プロンプト・期限ルール、録音分割の順序、再試行時の重複処理抑止、無料モードを検証します。外部AIへの実通信・iOSの実機録音とは区別してください。
