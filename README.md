# 議事録作成 — API料金なしの議事録ツール

iPhone・iPadのSafariで、ボイスメモと普段のChatGPTを使って議事録を作成します。APIキーは不要です。ChatGPT無料版には利用回数・入力の長さなどの制限があります。録音・文字起こしはボイスメモで行います。

## 使い方

1. ボイスメモの文字起こしをコピーし、アプリの「文字起こし」に貼り付ける。
2. 会議名・開催日・参加者を入力する。参加者と議事録プロンプトはいただいた内容を初期設定済みです。プロンプトは変更・保存できます。期限未指定のタスクは「本日18:00まで」のルールです。
3. 「ChatGPTへの依頼文をコピー」を押し、「ChatGPTを開く」から依頼文を貼り付けて送信する。
4. ChatGPTの回答をコピーし、アプリの議事録欄に貼り付ける。
5. 内容・担当者・期限を確認して保存。「LINEで共有」でLINEと送信先を選ぶ。

自動コピーが使えない場合は表示された依頼文を選択してコピーしてください。LINEへの送信状況はLINEで確認してください。ボイスメモの文字起こしが利用できるOS・端末・言語が必要です。長い会議はChatGPTの入力制限に応じて分割してください。

## 起動・公開

Node.js 22以上。外部npm依存・APIキーは不要です。

```sh
npm start
npm test
```

既定ポートは3000。`public/` をHTTPS対応の静的ホスティングにそのまま配置することもできます。公開後、Safariで開いて「共有 → ホーム画面に追加」で起動できます。クリップボード・共有機能はHTTPS環境で使用してください。Vercelに公開済みです：https://my-shop-bay-eta.vercel.app

## データと検証

文字起こし・議事録・プロンプトはブラウザ内に保存されます。他端末には同期しません。ブラウザデータの削除で消えるため、重要な議事録は別途保管してください。アプリから外部AIへの自動送信はありません。ChatGPTへの貼り付け・送信は手動で行います。共有端末での保存内容にご注意ください。

テストは依頼文の構成、未入力の拒否、API設定なしの画面配信、AIエンドポイントがないことを検証します。iPhone・iPadの実機でのコピー・LINE共有は未検証です。

## Vercelへのデプロイ

`vercel.json` は `public/` を静的サイトとして公開する設定です。APIキー、環境変数、ビルド処理は不要です。

CLIで公開する場合：

```sh
npx vercel login
npx vercel --prod
```

GitHub経由の場合は、このファイル一式をリポジトリに保存・pushした後、Vercelで `karin0385-bit/my-shop` をImportします。Root Directoryはリポジトリのルート、Framework PresetはOther、Output Directoryはpublic、Build CommandとInstall Commandは空欄です。

発行されたHTTPS URLをSafariで開いて試してください。ホーム画面への追加はSafariの共有メニューから行います。LINEが共有先に表示されない場合は「コピー」からLINEのトークへ貼り付けてください。デプロイ先URLが変わるとブラウザ内の保存データも別扱いになるため、継続利用には同じURLを使ってください。

## 操作を減らす更新

- 「文字起こしを貼り付け」でクリップボードから取り込みます。Safariの許可画面が出た場合は許可してください。使えない場合は長押し→ペーストで入力できます。
- 「依頼文をコピーしてChatGPTへ」で会議情報と既存プロンプトをまとめてコピーし、ChatGPTへ移動します。ChatGPTへの貼り付け・送信は手動です。
- 作業中の入力をブラウザ内に一時保存します。ChatGPTから同じURLへ戻ると復元します。回答は「ChatGPTの回答を貼り付け」で取り込めます。一時保存は議事録の保存一覧とは別で、ブラウザデータ削除時には失われます。
- 一時保存・コピーに失敗した場合はChatGPTへ自動移動しません。依頼文の手動コピーも利用できます。

### 純正ボイスメモを開く（初回設定）

iPhoneの「ショートカット」で新規ショートカットを作り、「アプリを開く」アクションの対象を「ボイスメモ」に設定します。名前を正確に「会議を録音」にしてください。アプリの「会議を録音」ボタンはこの名前のショートカットを実行します。設定前には使えません。録音ボタンはボイスメモ側で押してください。ホーム画面にショートカットを追加すると、Webアプリを経由せず開くこともできます。

iOS 27.0.1の実機確認はできていません。アクション表示・文字起こし対応は端末・OS・言語によって異なります。この実装はボイスメモから録音・文字起こしを自動取得するものではありません。対応しない場合はボイスメモを手動で開き、文字起こしをコピーして取り込んでください。
